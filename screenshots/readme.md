# Screenshots

This folder contains optional screenshots used in the documentation and GitHub README.

Screenshots are not required for the project to function, but they help users understand how the system looks and behaves.

Only placeholder filenames are included in the repository.  
You may replace them with your own images when running the system locally.

## Privacy Notes

When adding screenshots, make sure to avoid:

- Real IP addresses  
- Real TMDB API keys  
- Real Home Assistant entity names  
- Sensitive personal data  
- Your full Blu-ray collection (unless you want it public)

You may blur or crop sensitive areas if needed.
